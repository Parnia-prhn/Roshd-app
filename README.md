# رشد — اپ توسعهٔ فردی (Next.js + Postgres)

این پروژه یک اپ کامل با **بک‌اند واقعی** است: تسک‌ها، برنامه‌ریزی هفتگی، عادت‌ها،
اهداف، یادداشت روزانه و تایمر تمرکز — همه در یک دیتابیس Postgres ذخیره می‌شوند،
نه فقط در مرورگر شما. یعنی از هر دستگاهی که وارد لینک بشوید، اطلاعاتتان همان‌جاست.

## گرفتن لینک واقعی (بدون نصب چیزی، بدون خط فرمان)

### ۱) یک ریپازیتوری در گیت‌هاب بسازید
- وارد github.com شوید (اگر حساب ندارید، رایگان بسازید).
- روی **New repository** بزنید، یک اسم بدهید (مثلاً `roshd-app`) و **Create** کنید.
- در صفحهٔ ریپو، روی **Add file → Upload files** بزنید.
- تمام فایل‌ها و پوشه‌های داخل همین زیپ را همان‌جا بکشید و رها کنید (drag & drop) و **Commit changes** بزنید.
  (پوشه‌بندی حفظ می‌شود، نیازی به دستور git نیست.)

### ۲) پروژه را به Vercel وصل کنید
- به vercel.com بروید و با همان حساب گیت‌هاب وارد شوید.
- روی **Add New → Project** بزنید.
- ریپازیتوری‌ای که ساختید را از لیست پیدا کنید و **Import** بزنید.
- Vercel به‌صورت خودکار می‌فهمد این یک پروژهٔ Next.js است؛ نیازی به تغییر تنظیمات نیست.

### ۳) دیتابیس را وصل کنید (مهم‌ترین قدم)
- قبل از زدن Deploy یا بعد از اولین دیپلوی، وارد پروژه‌تان در Vercel شوید.
- برو به تب **Storage → Create Database → Postgres**.
- یک اسم بده و **Create** کن، سپس **Connect to Project** بزن و پروژه‌ات را انتخاب کن.
- Vercel به‌صورت خودکار متغیرهای اتصال (`POSTGRES_URL` و...) را به پروژه اضافه می‌کند.

### ۴) دیپلوی
- روی دکمهٔ **Deploy** بزنید (یا اگر قبلاً دیپلوی شده، از تب Deployments یک **Redeploy** بزنید تا متغیرهای دیتابیس اعمال شوند).
- بعد از حدود یک دقیقه، یک لینک واقعی مثل `https://roshd-app.vercel.app` می‌گیرید.
- جدول‌های دیتابیس در همان اولین باز شدن اپ به‌طور خودکار ساخته می‌شوند — کاری برای شما نمانده.

از این به بعد هر بار که لینک را باز کنید (از گوشی، لپ‌تاپ، هر جا) به همان دیتابیس وصل می‌شوید.

## اجرای محلی (اختیاری، برای توسعه‌دهنده‌ها)
```
npm install
npm run dev
```
برای اجرای محلی باید متغیر `POSTGRES_URL` را در فایل `.env.local` قرار دهید (مقدارش را از تب Storage در Vercel کپی کنید).
